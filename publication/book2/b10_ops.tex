\section{The gates}

Seven plan verifiers run from \texttt{.plan/.rea-tmp/} and record their exits in the dashboard;
the CodeFusion gate (\texttt{check-consistency.mjs}) runs 13 checks; the documentation
verifier refuses an off-by-one write. A gate is not advisory: a red gate stops the step. A test
is never weakened to make a gate green.
